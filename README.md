# Berlian Desktop Clock v1.0

A lightweight, minimalist, and transparent desktop clock for Windows 11, built as a Windhawk mod.

**Developer:** Muhammad Althaf Mahmudin  
**Organization:** Berlian Komputer  
**Country:** Indonesia 🇮🇩

## Screenshot

![Berlian Desktop Clock](screenshot.png)

## Features

- Large minimalist digital clock
- Transparent background
- Customizable clock position and size
- White and black text color options
- Optional date display
- Native C++ implementation
- Windows 11 desktop integration
- Wallpaper and sleep recovery mechanisms

## Installation

1. Install Windhawk.
2. Open Windhawk and create a new mod.
3. Copy the source code from the `.wh.cpp` file.
4. Compile and enable the mod.
5. Customize the clock using Windhawk Settings.
